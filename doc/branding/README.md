# VINX|FORMER ID identity reference

The [reference mockup](VINXFORMER-ID-v0.1-reference.jpg) was supplied by Vinx Scorza. Its text is the source for the firmware startup layout:

- PERSONAL PERFORMANCE FIRMWARE
- VINX|FORMER ID
- BUILT FOR ONE.
- SHARED WITH EVERYONE.
- NO ROADMAP. JUST EXPLORATION.
- MY WORKFLOW. MY RULES.

Representative colors sampled from the supplied JPEG (approximate because of JPEG compression): background `#101920`, primary text `#F4F7FC`, teal accent `#58DCC2`, secondary text `#98A2AB`.

The module display is 256 × 64 pixels and grayscale, so the firmware uses the composition and text hierarchy, with bright and medium intensity in place of the mockup's teal and gray. The full-color mockup remains the reference for future color surfaces.
