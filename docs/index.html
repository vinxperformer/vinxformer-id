A space for curiosity.

Creativity, experimentation, freedom: these are why I started messing with open-source firmware in the first place.

It was never about following a roadmap, meeting expectations, or turning a passion into another list of obligations. It was about curiosity. Breaking things, rebuilding them, making mistakes, chasing weird ideas, and occasionally creating something unexpected.

It's easy for something you love to slowly start feeling like something you owe to others.

And that's not why I started!

I chose open source and started modifying firmware to feel a little more free, not a little more trapped.

So I keep rethinking things. Stripping away what I don't need, making room for what inspires me, and imagining different directions for my little electronic playground.

Something more personal. More experimental. Maybe a little unpredictable. And definitely driven by my own curiosity.

That's what VINX|FORMER ID is: an extremely personal fork.

This doesn't mean turning my back on the community or on sharing my work. Quite the opposite. I still believe in the beauty of letting others explore what you've created. But sharing something doesn't mean surrendering the freedom to decide what it becomes.

Feature requests are not automatically part of VINX|FORMER ID. I consider them when they serve me personally or can become part of my workflow.

No big promises. No release dates. No expectations. Just me, some code, a machine I love, and a head full of bizarre ideas.

Let's see where this goes.

What changes in VINX|FORMER ID compared with Vinx PER|FORMER.

VINX|FORMER ID grows out of Vinx PER|FORMER as a separate firmware line. These are the operational changes in ID, ordered by their impact on performance.

  • Eight CV modulators. Mod 1 drives CV 1 through Mod 8 driving CV 8. Each starts Off; On replaces only that output's track CV. Sine, Triangle, Saw Up, Saw Down, Square, Random, and ADSR are adapted from modulove/performer. Choose 0–1/2/3/4/5 V or ±1/2/3/4/5 V.
  • Permutation on selected Note tracks. Reroll step position and pitch on one or several tracks. Compare ORIGINAL and PERMUTED before applying; every reroll starts from the captured original. MOVE and PITCH default to ±3.
  • Random Shape on Curve tracks. Write new shapes into the active steps at each track-loop boundary. Only Shape changes. The per-track switch is saved; Off leaves the last shapes in place.
  • Random Project Scale. Repeat SHIFT + PERF to audition musical scales; SHIFT + PATT restores the stored scale. Sequence steps and the saved scale stay intact.
  • Reversible Project scale changes. Changing scale leaves stored Note steps intact. Returning restores the same pitches if those steps were not edited; the Project root remains fixed.
  • Removed track types. Stochastic and Logic Tracks are no longer available in VINX|FORMER ID.
  • Removed controller paths. Launch Control XL support and external 16-step editing are gone. The supported controller profiles are Launchpad Pro Mk1 and Launchpad Mini Mk3.
  • Removed simulator releases. VINX|FORMER ID ships neither a desktop nor a web simulator; simulator code remains for development tests.

If you come from Mebitek.

VINX|FORMER ID retains the Vinx PER|FORMER workflow changes built on the Mebitek fork, alongside the ID changes above:

  • Generate, compare, apply. Random, Acid, Chaos, and Euclidean provide source/preview comparison and Apply or Cancel. Acid can write one layer or a Gate + Note + Slide phrase; Chaos can target a sequence or pattern.
  • Edit selected steps. Copy, Paste, and Duplicate preserve selection gaps. Tied Note steps share pitch edits; Curve steps expose Gate Offset and Gate Length.
  • Change playback in place. A Fill divisor override changes playback temporarily without changing the saved divisor. Note, Curve, and Arp tracks can output Gate or a length-controlled Trigger.
  • Filter MIDI input. Accept Notes, CC, Program Change, Pitch Bend, and Aftertouch independently. Note Off still releases active notes when incoming Notes are disabled.
  • Perform from Launchpad. Pro Mk1 and Mini Mk3 provide track-aware generator selection, preview, reroll, cancel, and apply.

What remains from Westlicht and Mebitek.

From Westlicht PER|FORMER

  • Eight tracks, up to 64 steps per sequence, 16 patterns, Song, and a temporary pattern snapshot.
  • Note, Curve, and MIDI/CV tracks; eight CV/Gate output pairs, MIDI, clocking, scales, and project storage.
  • CV/MIDI routing, step conditions, probability, and the core panel workflow.

From Mebitek PER|FORMER

  • Arpeggiator Track, pattern follow, and quick pattern chaining.
  • Sequence save/load slots, selected-step movement and undo, and expanded Curve CV recording.
  • Launchpad performance controls and panel shortcuts to Project, Routing, MIDI Output, and User Scale pages.

VINX|FORMER ID v0.1.7 is available. Back up projects before saving: this version uses the new Version43 project format, and older firmware may not reopen saved projects.
